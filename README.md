# कथाबस्तु · Kathabastu shorts

Pipeline for Nepali 2D animated shorts (comic and folk-art styles) with ElevenLabs voices,
CC0 sound effects (wyzowl/sfx-kit) and a synthesized tanpura/bell background.

- `AGENT.md` — the step-by-step playbook a scheduled run follows.
- `build.py episodes/<slug>` — renders story.js + voice clips into `video.mp4`.
- `engine/` — drawing helpers, characters, timing runtime. `fonts/` — Mukta and Baloo 2 (SIL OFL).
- `episodes/` — one folder per published episode.
